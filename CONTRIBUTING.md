# Contributing

1. Create a focused branch or pull request.
2. Explain the product problem and the surfaces affected.
3. Update `tokens/tembus.tokens.json` first when a new semantic value is needed.
4. Update platform outputs and documentation in the same change.
5. Run `npm run validate`.
6. Include before/after screenshots for meaningful visual changes and note responsive/accessibility behavior.

Avoid adding one-off colors, undocumented components, or visual changes that only work in one role or one theme.
