# TEMBUS brand assets

These working assets are copied from the current TEMBUS/LANCAR product repository so consuming teams have a known starting point. Use the approved vector master for production print or high-resolution output when the brand team provides one.

## Which logo to use

| Surface | Asset | Usage |
|---|---|---|
| Light or white surface | `tembus-logo-green.webp` | Customer web, reports, presentations, and other light layouts |
| Dark or forest-green surface | `tembus-logo-white-wordmark.webp` | Full TEMBUS wordmark for app home/header, dark mode, and dark hero sections |
| Dark or forest-green surface, compact area | `tembus-logo-white.png` | Compact brand-mark context when the full wordmark does not fit |
| Small brand-mark context | `tembus-mark-color.png` | Use only when the available artwork is large enough for the intended size |

Do not recolor, stretch, rotate, crop, or add effects to the logo. Keep sufficient clear space around every logo. The green logo is not intended for dark surfaces, and the white logo should not be placed directly on a light surface without a sufficient dark container.
